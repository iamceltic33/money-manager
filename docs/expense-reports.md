# Отчёты по расходам

Реализовано 2026-10-05. Экран `/reports` открывается кнопкой «Отчёты» на главной и из бокового меню. Экран находится в `src/pages/reports`, роут — тонкий адаптер.

## Периоды

- Неделя по умолчанию: с понедельника текущей недели по сегодня.
- Месяц: с первого числа текущего месяца по сегодня.
- Год: с 1 января текущего года по сегодня.
- Период: две выбранные даты, включая обе границы.

Границы рассчитываются по локальным календарным датам устройства. В SQLite используются начало первого дня и исключительная граница начала следующего дня после последнего. При возвращении на экран текущая дата обновляется.

## Данные и диаграмма

В SQLite суммируются все расходы аккаунта в выбранном периоде по `category_id`; лимиты страниц истории не применяются. Доходы не участвуют. Исключения из прогноза не влияют на отчёт. У операций без категории отдельная группа «Без категории»; удаление категории сохраняет её расходы в этой группе.

Горизонтальные столбцы отсортированы по убыванию суммы. Самый большой столбец занимает всю ширину, остальные пропорциональны ему. Для категории отображаются название, сумма KZT, доля общих расходов и количество операций. Цвет берётся из категории. Над диаграммой показаны общая сумма и количество расходов.

При изменениях операций и синхронизации отчёт перечитывается через `useTransactionResource`. Ответы от предыдущего аккаунта/периода не отображаются. Предусмотрены загрузка, повтор чтения после ошибки и пустой период. Даты используют существующий DateField; прокрутка учитывает клавиатуру через KeyboardAwareScrollView.

## Проверки

`node --test tests/expense-report.test.cjs tests/transaction-resource.test.cjs` — 5 тестов: календарные границы, воскресенье, високосная дата, суммы более одной страницы истории, дробные суммы, исключения прогноза, доходы, изоляция аккаунтов, удаление категории и защита от устаревших ответов.

Проверка на Android/iOS остаётся необходимой: переключение периодов, календарь и отображение диаграммы на устройстве.
